- UI/UX Standards: Secondary labels, metadata tags, and small utility buttons must use the class `text-[10px] font-bold uppercase tracking-wider`. Internal component titles and form labels (e.g., within settings and danger zones) use `text-sm font-semibold`. Main page titles and hero components are generally scaled down by one increment (e.g., `text-3xl` to `text-2xl`), including responsive font modifiers (e.g., `md:text-4xl` to `md:text-3xl`), to maintain the platform's high-density technical aesthetic.
